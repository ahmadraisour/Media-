# motion-edit — أسلوب المونتاج المعتمد (كي فريم)

أول تطبيق: فيديو المتاهة، النسخة النهائية v11 (47.8 ثانية، 23/10/2026).

## الطبقات
1. **base3.mp4**: الفيديو الأصلي بعد القص (`maze/cut.py` من reel-edit-v1.mp4). ما بيرتفع هون لأنه كبير، والأصل عند أحمد.
2. **الضباب حول المشاهد**: `comp.py` بيبني ماسك من أوقات المشاهد، وبيطبّق gblur sigma 28 على وجه أحمد قبل كل مشهد وبعده.
3. **maze_broll.mp4**: متاهة الحل (`maze/maze.html` + `maze/mazer.py`، توليد Prim بـseed 13، مقلوبة: النهاية فوق).
4. **ov.html**: طبقة شفافة فيها المشاهد والكي فريم والكتابة المتحركة والترجمة والبطاقات وشريط التقدّم. بتنرسم فريم فريم بـ`render.py` (Playwright، 30fps).

## التشغيل
```
python3 render.py              # كل الفريمات في fr/
python3 render.py 9.2 9.4      # أوقات محددة للفحص
python3 comp.py                # الماسك + التركيب النهائي
```

## المشاهد (SC في ov.html)
كل مشهد: `[بداية, نهاية, نوع, beats]`، وكل beat: `[t0, t1, كلمات صغيرة, كلمات كبيرة]` (أرقام الكلمات من subs3.json).
- **TPL** = HTML المشهد، و**UPD** = دالة الحركة لكل فريم (t نسبي، T مطلق).
- kid: خط قلم بينرسم والإيد بتلحقه، مع ✕.
- wall: متاهة من فوق (`L/aerial.png`)، 3 خطوط حمرا بتعلق بالحيط على "بالحيط / يمين / يسار"، مع حيط مضوي وهزة. ما في ميلان.
- mars: الكوكب بيكبر، ورائد الفضاء بيطلع من تحت مع غبار. ما في نجوم وما في طفو.
- joy: الولد مع عمق 2.5D وجزيئات ذهبية. شلنا الخط الأخضر (قرار أحمد).
- maze / shop / money: عمق 2.5D، دفشة كاميرا، تغميق ورمادي على الكلمات القوية، مصاري بتطير.

## الأدوات
- `cut.py in.png out.png`: قص الشخص (u2net_human_seg.onnx، متغير البيئة U2NET).
- `inp.py src.jpg cut.png bg_out.jpg`: خلفية بدون الشخص (OpenCV inpaint) لعمق 2.5D. حركة الشخص لازم تضل ≤ 30px.
- صور B-roll: Canva generate-image، وبعدين تصدير 1080×1920 عبر التصميم المساعد DAHYqXnlBA4.
- `demo/`: تجربة 3 ثواني لمشهد واحد (القاعدة: جرّب قبل ما تطبّق على كل الفيديو).

القواعد الكاملة لأسلوب المونتاج موجودة بذاكرة أحمد (السكيل)، بقسم "أسلوب المونتاج المعتمد".
